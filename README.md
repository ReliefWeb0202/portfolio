# portfolio

個人制作実績やスキル、自身のプロフィールを伝えるための個人ポートフォリオサイトです。
実用性・メンテナンス性の高いコード設計を意識して制作しました。

---

## 制作概要
- **制作時間**：約20時間（デザイン試行錯誤を含む）
- **担当範囲**：デザイン定義、ワイヤーフレーム作成、フロントエンドコーディング（HTML / CSS）
- **使用技術・ツール**：
  - 言語/フォント：HTML5, CSS3, Google Fonts
---

## 制作のポイント・工夫した点

1. **試行錯誤から「デザインルール」の確立へ**
   初期段階ではデザインの方向性に悩み、何度もレイアウトや配色のやり直しを行いました。試行錯誤を通じてベースとなるデザインシステムやルールを明確にし、一貫性のあるデザインを構築しました。太い黒枠線、くっきりとしたドロップシャドウ、主張を意識したパーツ配置を取り入れ、力強さとモダンさを両立させたレトロポップな世界観を表現しました。

2. **実用性とコード品質の意識**
   見た目のインパクトだけでなく、レスポンシブ時の表示崩れ防止や、CSS変数（`var()`）を用いたカラー・スタイルの管理など、保守性・メンテナンス性の高いコード設計を徹底しました。

---

## 制作を通して学んだこと・今後の活かし方

デザインで迷走した経験から、**「事前にコンセプトやベースとなるデザインシステムを強固に固める重要性」**を実体験として学ぶことができました。

一方で、デザインの方向性が決まってからの実装速度や精度の高さは自身の強みであると実感できたため、今後の実務でも最初の要件・デザイン定義を大切にし、効率的かつ高品質なコーディングを行っていきます。
